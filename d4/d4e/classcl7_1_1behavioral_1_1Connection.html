Detailed Description

RAII handle for a Signal subscription. Disconnects automatically when destroyed (unless released or already disconnected). Deliberately not nested inside Signal<Args...>, so a caller can hold connections to signals of differing argument signatures uniformly (e.g., in a single std::vector<Connection>) for one-shot mass-disconnect.

Safe to outlive the Signal it was connected to: disconnecting then is a no-op (see Signal's Impl/weak_ptr design).
