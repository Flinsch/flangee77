Detailed Description

A scrollable, vertically stacked list of arbitrary rows (see add_item()), each wrapping one caller-supplied Face, with single-select-by-click/arrow-keys built in (see get_selected_index()/set_selected_index()), Ctrl-clicking the selected row to clear the selection included. Internally just a themed ("list_box") ScrollPanel (see Panel) with its vertical scrolling reused wholesale and its horizontal scrolling permanently disabled/hidden (rows always span the full available width). Each row (see Row, themed "list_box_row") is purely a disabled decoration around its own content Face; hit-testing/selection/keyboard navigation is instead handled by a single RowArea spanning all rows at once (see RowArea), both on the content Face's behalf (clicking anywhere in a row, its disabled content included, selects that row) and so the whole list has one coherent focused face for arrow-key navigation, rather than each (otherwise disabled) row needing to be its own focusable Control.

No removal is supported yet (the underlying Collection itself doesn't support removing a child either, see Collection).

◆ remove_item()

void fl7::gui::faces::ListBox::remove_item ( int index)

Removes (and destroys, along with its content Face) the item at the specified index; an out-of-range index is ignored. Every later item's own index shifts down by one to match. If the removed item was the currently selected one, the selection is cleared (-1) rather than jumping to whatever item now happens to occupy its old position; a selected item at a later index just keeps tracking the same (still selected) item, re-numbered down by one. Either way, get_selection_changed() only fires if the index this list reports actually changes as a result.
