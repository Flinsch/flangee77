Detailed Description

A plain ScrollPanel themed "list_box" instead of "scroll_panel", so a list box's chrome can be styled independently of a plain ScrollPanel's.

Member Function Documentation

◆ _get_theme_key()

cl7::u8string_view fl7::gui::faces::ListBox::Panel::_get_theme_key ( ) const
inlineoverrideprotectedvirtual

Returns this face's role/key for theme-based style resolution (see get_effective_style()), e.g., "window", "button", etc. Default: empty, meaning this face type doesn't participate in theming (falls straight through to the ordinary inherited-override/last-resort-default style). Override in concrete types that do.
