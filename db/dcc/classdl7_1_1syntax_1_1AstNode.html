Detailed Description

template<typename Ttype = unsigned>
class dl7::syntax::AstNode< Ttype >

Represents a node in an abstract syntax tree (AST). Unlike a CST node, an AST node represents the semantic structure of parsed code, omitting unnecessary syntactic details. AST nodes are typically derived from CST nodes but focus on representing program logic.
