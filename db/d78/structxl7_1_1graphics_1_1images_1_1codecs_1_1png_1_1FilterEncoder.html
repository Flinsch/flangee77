Applies PNG scanline filters to the given raw pixel data. src must contain height * bytes_per_scanline bytes of unfiltered pixel data. dst receives height * (1 + bytes_per_scanline) bytes, with a filter type byte prepended to each scanline. FilterType::Auto selects the filter per scanline that minimizes the sum of absolute values of the filtered bytes (adaptive filtering).
