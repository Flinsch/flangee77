Detailed Description

Abstract class for rasterizing glyphs into images, for example as a "classic" bitmap, a signed distance field (SDF), or a multi-channel signed distance field (MSDF), and (optionally) calculating the positional offset of a rasterized image relative to the typographic origin of the glyph.

void fl7::fonts::raster::AbstractRasterizer::set_cache ( GlyphRasterCache * cache)
inlinenoexcept

Sets (or clears, via nullptr) a disk-backed cache to consult before rasterizing a glyph, and to populate after rasterizing one. Not owned: the caller must keep it alive for at least as long as this rasterizer. Disabled (nullptr) by default, so this has zero effect on behavior or performance unless explicitly opted into.
