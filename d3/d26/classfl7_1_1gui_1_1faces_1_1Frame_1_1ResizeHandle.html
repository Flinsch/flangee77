Detailed Description

A small, actively interactive drag grip in the frame's own bottom-right corner (see Frame::_on_size_changed()'s own repositioning), letting the user resize it. Deliberately NOT a disabled/passive decoration, unlike Frame's own _title_label (or TrackControl's handle): it overlaps the frame's content area, which, unlike the title bar's own otherwise-empty strip, is both enabled and (being added first, in Window's own constructor) further back in z-order, so it would otherwise swallow the click before it ever reached Frame's own mouse hooks. Handles dragging entirely on its own instead, resizing its owning frame directly. Not a Control either: drag-only, no keyboard equivalent (yet), so no Tab stop.
