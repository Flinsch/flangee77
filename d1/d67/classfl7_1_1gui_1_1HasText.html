◆ get_text_box_size()

virtual std::optional< ml7::Vector2f > fl7::gui::HasText::get_text_box_size ( ) const
inlinevirtual

Returns the box size to actually lay the text out against, if different from the face's own get_size() narrowed by its own effective padding (see Face::get_effective_padding()); e.g., narrower still, to leave room for a scroll bar (see faces::TextField's multiline mode). Overriding this means taking over accounting for that padding yourself (see faces::TextField's own _effective_text_box_size()); render::AbstractRenderer::_draw_face() only applies it on your behalf while this stays nullopt, the default.

Reimplemented in fl7::gui::faces::TextField.

Returns how far the displayed text is currently scrolled within its own box: subtracted from the box's own position before laying out/drawing/ hit-testing it, same sign convention as Collection::get_scroll_offset(). Default: none; only faces::TextField's multiline mode actually scrolls.
