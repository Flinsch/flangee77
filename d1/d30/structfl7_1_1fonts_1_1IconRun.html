Detailed Description

Places an Icon at a single code point position (slot) within a single draw call. The code point actually present at that position in the text is skipped/ignored: the IconRun entirely overrides both its advance width (layout) and its visuals.

icon_runs passed to a single draw call must be sorted by codepoint_index (same convention as StyleRun's codepoint_begin).
