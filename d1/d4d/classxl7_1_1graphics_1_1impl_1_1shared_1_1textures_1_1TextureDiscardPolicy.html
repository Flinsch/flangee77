Detailed Description

template<typename TExtent = graphics::textures::TextureExtent, typename TRegion = graphics::textures::TextureRegion>
class xl7::graphics::impl::shared::textures::TextureDiscardPolicy< TExtent, TRegion >

Decides whether a hardware texture update should discard the entire pixel data instead of updating only the dirty region.
