Detailed Description

A TrackControl (horizontal or vertical) with a fixed, square handle by default (see TrackControl for the shared value/step model and click/drag/keyboard/wheel interaction). Set a handle fraction (see set_handle_fraction()) to instead give it a handle whose length itself is meaningful, e.g., ScrollBar builds its middle, draggable part from exactly that.
