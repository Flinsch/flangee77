◆ resolve_effective_viewport()

Viewport xl7::graphics::RenderingContext::resolve_effective_viewport ( ) const

Returns the effective viewport based on the current pipeline states, starting with any explicitly set viewport and then depending on the bound (primary) render target or bound depth/stencil buffer. Otherwise, the default viewport of the (default) back buffer is returned.

◆ synchronize_hardware_state()

bool xl7::graphics::RenderingContext::synchronize_hardware_state ( )

Performs a forced synchronization with the hardware state. This function is called automatically after the rendering context has been created and does not actually need to be used any further, perhaps after resetting the rendering device, that's it.
