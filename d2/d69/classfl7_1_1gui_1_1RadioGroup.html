Detailed Description

Ties together an arbitrary set of faces::RadioButton instances so that checking one unchecks whichever other one (if any) was previously checked, deliberately independent of the Face tree (unlike, e.g., some other toolkits' "same parent container" grouping). Doesn't track its full membership, only whichever single member is currently checked (if any): enough to enforce mutual exclusion without needing to enumerate the group otherwise.

Forgets button as the checked member, if it currently is one. Called on an explicit uncheck (RadioButton::set_checked(false)) and on a checked member's destruction, so this group never keeps a dangling pointer or a stale "checked" bookkeeping entry.
