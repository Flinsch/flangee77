Detailed Description

Represents a single keyboard's state (or the aggregate of all connected keyboards, which is fed the same way, just with OR'd values instead of a single physical device's raw values).

◆ get_text_input()

const cl7::u8string & xl7::input::Keyboard::get_text_input ( ) const
inline

Returns the composed text input received during this frame. Unlike the key state above, this already reflects keyboard-layout translation and dead-key/IME composition (fed from WM_CHAR on Windows, for example, not from the raw key codes), so it's what a GUI text field should consume.

Note: WM_CHAR isn't attributable to a specific source keyboard, so in practice only the aggregate keyboard's text input is ever populated, individual keyboards' text input stays empty.
