Detailed Description

Base class for all GUI elements ("faces"): position/size (relative to its parent), visibility/enabled state, style resolution, and the input-event hooks. Doesn't own children itself (see Collection for that), so a plain face is a leaf. Absolute (screen) position is computed on the fly during hit-testing/rendering traversal, not cached (fine at GUI scale). Knows nothing about drawing/rendering itself, that's entirely up to implementations of render::AbstractRenderer.
