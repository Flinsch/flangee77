Detailed Description

A Panel-like background/border chrome around arbitrary, publicly addable children, except its content is allowed to be larger than its own (viewport) bounds: scrolled into view via get_scroll_offset()/set_scroll_offset(), clamped to get_content_size() (set explicitly by the caller: there's no layout system yet to compute a content size from the children themselves, see Container). Overflowing content is still clipped to this face's own bounds regardless (see Collection::clips_children()), same as any other Collection's. This face has no opinion on how get_scroll_offset() actually gets driven: pair it with a ScrollBar (or two, one per axis) yourself, forwarding its get_changed() into set_scroll_offset().
