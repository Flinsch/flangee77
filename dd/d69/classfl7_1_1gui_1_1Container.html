Detailed Description

A Collection with arbitrary, publicly addable children (e.g. Panel, GroupBox). Intended to eventually position its children via a pluggable layout (see the planned gui::layout namespace: DefaultLayout/BoxLayout/ GridLayout) – not implemented yet, children just keep whatever position/ size they're given for now.

◆ remove_child()

void fl7::gui::Collection::remove_child ( Face & child)

Removes (and destroys, along with its own descendants, if any) the specified child of this collection, which must actually currently be one. Removal is immediate/synchronous, not deferred to some later, safe point: the caller is responsible for never removing a face from within its own (or one of its descendants') callback (_on_click() etc.), which would destroy it mid-call, while one of its own member functions is still running. Clears whichever of the owning Shell's hovered/pressed/focused face (if any) falls within the removed subtree first, so it's never left dangling (see Shell::_handle_face_removed()).
